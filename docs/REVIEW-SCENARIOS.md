# RoohKeSur Studio review scenarios

These are dry-run/pilot acceptance tasks, not completed media tests. Use privately supplied original inputs. No paid generation is part of structural CI.

| Request | Observable acceptance |
| --- | --- |
| Provide a poem and request Suno preparation | Copy-ready original lyrics with economical tags, separate soulful style and pronunciation instructions; wording retained, proposed refrain repetition explicit; awaiting_song, no fabricated finished video. |
| Return a 3-minute selected song and ask for a reel | Both 30-second portrait and coherent 3-minute landscape outputs; song identity and actual timings retained; complete package and full playback review. |
| Return a song outside 2-4 minutes | Duration issue is surfaced before forced verse edits/repeats; independent visual preparation can continue. |
| Request six-line artwork | Exact selected lines, a meaningful distinctive detail, readable shaped script and two deliberately composed platform images; no unrelated video generation. |
| Supply a recitation with an ordinary background | Human voice preserved; useful sound/cut improvements; background changes require credible temporal masking and full-motion review. A still frame edit is not reported as a completed video change. |
| Correct only one overlay | Edit text/timing and rebuild; preserve accepted footage with no new video generation. |
| Required cloud tool is missing | Complete unaffected work; report the exact remaining operation; no desktop fallback or invented result. |
| Provider preview exists but export is incomplete | Do not report saved/ready; durable cloud assets and accessible outputs must be verified. |
| Complete a production | Ready for your review with all outputs; user review precedes publication; notification delivery not claimed without a configured event. |
| Public repository / private poem | No original poem, recording, private asset identity or credentials enters Git/CI logs. |

The build check validates packaging and file relationships only. Passing it does not establish performance quality, Hindi/Urdu rendering, media connectivity or host notification behaviour.
