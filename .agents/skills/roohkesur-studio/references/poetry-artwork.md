# Artistic poetry images

Input is the supplied poem or chosen excerpt. Deliver an Instagram composition and a YouTube Community composition.

## Editorial and art direction

Choose 4-6 exact lines with a coherent thought unless the creator selected them. Do not silently improve the poem, change its spelling or detach lines from meaning. If fewer lines are available, use the available authorised text and resolve a materially different scope.

Find one distinctive artistic detail tied to the poem. Examples of mechanisms, not mandatory imagery: a reflection that reveals another season, light emerging from an unexpected object, a doorway suspended in a quiet landscape, or an ordinary object carrying memory. A short concept should state why that detail serves the selected verse.

Use enough negative space for the poem and a clear reading path. Let imagery, texture, light, palette and typography work together. Avoid using a busy generated background as decoration behind unreadable text. Keep a recognisable RoohKeSur signature without overwhelming the verse.

## Production

1. Use an available cloud image tool to produce or edit the artwork, retaining the user-supplied references when present. Discover exact tools and parameters; do not assume the local installation of an application supplies cloud access.
2. Prefer a text-free image plus a separate Unicode type layer or rebuildable layout. If lettering is generated within the image, inspect every character and keep the original text separately.
3. Choose script-capable fonts and a shaping renderer. Devanagari matras/nukta, Urdu joining and right-to-left direction, punctuation and mixed numerals require inspection in the rendered output.
4. Preserve the poetic line breaks and comfortable line spacing. Animate whole words/lines rather than splitting grapheme clusters when motion is requested.
5. Create a portrait Instagram feed layout, initially 1080 x 1350, and a YouTube Community layout, initially square 1080 x 1080. These are working design defaults; check the current platform preview and the user's request, then recompose rather than treating one crop as final.
6. Export sharp image files in a supported format, separate background, original text, caption and supported editable/rebuild material.

OpenAI image generation/editing, Adobe, OpenArt, Higgsfield or ImagineArt may supply the background depending on available authorisation and operation fit. Use a cloud design/compositing route for final type where needed; do not promise a PSD/AI/native project unless the actual service produced it.

## Acceptance

Inspect both final images at full resolution and phone-like size. Confirm exact lines, attribution, shaped glyphs, clear hierarchy, background detail, contrast, margins and feed/community previews. No obscured face or accidental generated lettering should compete with the poem.

Deliver both platform images with captions, source/layout information and durable private output references. Report ready for review. Publication follows the creator's approval.
