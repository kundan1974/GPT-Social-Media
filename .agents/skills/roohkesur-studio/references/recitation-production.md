# Professional recitation production

The supplied recording governs the performance. Preserve the creator's voice, face and intentional poetic rhythm. If input is audio-only, create narrated visuals without pretending the creator filmed them.

## Build the edit

1. Save the untouched recording privately and inspect format, duration, picture and sound.
2. Transcribe against the original poem and align to actual speech. Identify mistakes, omissions and intentional changes separately. Automatic transcription is a draft; Hindi/Urdu names and poetic diction require correction.
3. Remove unwanted mistakes and accidental dead time while keeping meaningful pauses, breath, line order and the emotional turn. Do not force speech to an arbitrary pace.
4. Improve noise, clicks, level consistency and intelligibility conservatively. Compare before/after; avoid erasing vocal character or treating every breath as a defect.
5. Establish a suitable visual treatment: natural skin, coherent colour, appropriate lighting impression, uncluttered composition and supporting shots that deepen meaning.
6. Add corrected captions and restrained graphics. Keep editable Unicode text and timings.
7. Use supplied or authorised music/ambience only when it serves the performance. Manage music beneath speech; avoid competing sung vocals unless the creator requested that combination.

A generated host, synthetic replacement line or voice clone is a separate decision, not an automatic repair. The user supplies performance; the skill supplies the finished production.

## Background change

A video background replacement needs temporal subject segmentation or masking and a cloud compositor. Check that the actual cloud service supports the whole moving recording. OpenAI image tools can create or edit backdrop artwork; editing a still frame does not replace a video background.

Protect face and body identity. Review mask stability around hair, hands and clothing, edges during movement, foreground/background depth, lighting, contact shadows, and lip/audio sync through the full result. If the route cannot perform a credible replacement, complete other editing and identify the precise remaining operation. Do not silently replace the creator with generated footage or fall back to a desktop application.

For a green-screen source, use a verified cloud keying/compositing route. For an ordinary background, require a suitable temporal segmentation route; a still-image background-removal tool is insufficient.

## Paired outputs

For a reel request produce a 30-second 9:16 social version and an approximately 2-4-minute 16:9 YouTube version when the source supports that length. Select a self-contained passage for the short. Preserve the full coherent performance for the longer version; reframe and compose each format deliberately.

If the recording does not support the requested long duration, resolve natural length or additional input. Do not duplicate recited verse or fabricate new narration to fill time. A separate request for one finished recording keeps its requested scope.

## Review and delivery

Listen to complete audio; view the complete exported video. Check the poem against spoken/caption text, motivated cuts, realistic skin, continuity, shape/RTL rendering, stable background edges, intelligibility, clipping, sync, readable framing and endings.

Deliver the requested versions, covers, caption.txt, MUSIC.md, UPLOAD-PACKAGE.md, original/clean sources and supported editable/rebuild material in private cloud storage. A generation job or displayed preview is not proof of final export or playback review.
