# GPT-Social-Media

Cloud-only poetry and social-media production workspace.

## RoohKeSur Studio

The skill at [.agents/skills/roohkesur-studio/SKILL.md](.agents/skills/roohkesur-studio/SKILL.md) supports:

1. **Poem to song/video:** prepare Suno lyrics with structure tags, style and soulful-performance direction; wait for the creator's final song; produce a 30-second vertical social reel and an approximately 2-4-minute horizontal YouTube video.
2. **Poetry artwork:** compose 4-6 exact poem lines over a distinctive artistic background, with Instagram and YouTube Community versions.
3. **Recitation production:** professionally edit the creator's recording, preserve the voice, improve sound and presentation, and replace backgrounds only through a verified cloud video workflow.

Example requests:

- "Use $roohkesur-studio to prepare this poem for Suno."
- "Here is the final song. Build the Instagram reel and YouTube version."
- "Make poetry artwork from these six lines."
- "Polish my recorded recitation into the paired video package."

See [cloud activation](docs/CLOUD-ACTIVATION.md) for the environment checks and [review scenarios](docs/REVIEW-SCENARIOS.md) for pilot acceptance.

The cloud build validates structure and packages the complete skill folder. Its ZIP is an authoring/install bundle, not proof of ChatGPT installation or provider access. Source remains in Git; CI artifacts are temporary conveniences.

This repository is public. Store original poems, recordings, media, private production manifests and credentials in private cloud storage. No provider credentials are needed by the validation build.
